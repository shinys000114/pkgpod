# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately on GitHub: the repository's **Security** tab, **Report a
vulnerability**. Only the maintainers see the report.

Say which version you run (`pkgpod --version`), what is affected (a
format, a listener, the API, the console, the CLI), how to reproduce it
and what it lets someone do.

The report and the fix stay private until a release with the fix is
out; a security advisory then describes the problem and the versions it
affects.

## Supported versions

Fixes are made in the newest release.
